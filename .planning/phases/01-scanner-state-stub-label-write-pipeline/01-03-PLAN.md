**Helper: \_write_if_not_exists(path: Path, content_bytes: bytes) -> bool:**
Per RESEARCH.md Pattern 3 (clobber defense layer 2):

```python
def _write_if_not_exists(path: Path, content_bytes: bytes) -> bool:
    """Write bytes to path only if it does not already exist. Returns True if written."""
    try:
        fd = os.open(str(path), os.O_CREAT | os.O_EXCL | os.O_WRONLY, 0o644)
    except OSError as e:
        if e.errno == errno.EEXIST:
            return False   # file already exists -- clobber defense layer 2
        raise
    try:
        os.write(fd, content_bytes)
        os.fsync(fd)
    finally:
        os.close(fd)
    return True
```

Include inline comment: "# O_CREAT|O_EXCL is atomic on POSIX -- no race between check and create"

**Helper: \_reconcile_crash(vault_file: Path, body_bytes: bytes, session_id: str, state: dict, fingerprint: dict) -> str:**
Per D-25 crash reconciliation:

- Compute expected_hash = hashlib.sha256(body_bytes).hexdigest()
- Read existing_hash = \_read_auto_label_hash(vault_file)
- If expected_hash == existing_hash: this is a crash recovery -- update state (add session_id to synced_session_ids, record fingerprint), save_state, return "reconciled"
- If hashes differ: this is a genuine collision (slug collision or user-edited file), return "collision"

**cmd_write(args) -- the full pipeline per D-24:**

1. \_require_config() to get config
2. Read label JSON from stdin: label_input = sys.stdin.read(). Parse with json.loads(label_input). Validate that "title" key exists (fatal error if missing, per D-02). Unknown keys are ignored.
3. Load state
4. **Clobber defense layer 1 (CORE-08):** Check if args.session_id is in state["synced_session_ids"]. If yes: print "skipped: already_synced" and return (exit 0).
5. Locate the JSONL file: search PROJECTS_DIR for a file with stem matching args.session_id. If not found, print error and sys.exit(1).
6. Get session date: \_get_session_date(jsonl_path)
7. Get markdown body: \_get_markdown_body(args.session_id) via subprocess
8. Get session metadata: \_extract_session_metadata(jsonl_path)
9. Compute body_bytes = body.encode("utf-8") (the rendered markdown from step 7)
10. Compute auto_label_hash = hashlib.sha256(body_bytes).hexdigest()
11. Build frontmatter fields dict: combine label fields (title, gist, tags, coherence_score, needs_review) + metadata (model, token_count, msg_count) + config (machine=config["machine_label"]) + computed (project=jsonl_path.parent.name, session_id=args.session_id, hostname=socket.gethostname(), synced_at=datetime.now(timezone.utc).isoformat(), auto_label_hash=auto_label_hash)
12. Render frontmatter: frontmatter_str = emit_frontmatter(fields)
13. Build final_bytes = (frontmatter_str + "\n" + body).encode("utf-8")
14. Resolve vault filename: \_resolve_vault_filename(config, label, session_date, args.session_id)
15. **Clobber defense layer 2 (CORE-09):** written = \_write_if_not_exists(target, final_bytes)
16. If not written (file exists):
    - Build fingerprint for this session: {"mtime": jsonl_path.stat().st_mtime, "size": jsonl_path.stat().st_size}
    - result = \_reconcile_crash(target, body_bytes, args.session_id, state, fingerprint)
    - If "reconciled": print "skipped: already_synced (recovered from interrupted write)" and return
    - If "collision": print error "File already exists and content differs: {target}. Manual review needed." and sys.exit(1)
17. If written: update state:
    - state["synced_session_ids"].append(args.session_id)
    - state["fingerprints"][args.session_id] = {"mtime": jsonl_path.stat().st_mtime, "size": jsonl_path.stat().st_size}
    - state["last_run_at"] = datetime.now(timezone.utc).isoformat()
    - save_state(state)
18. \_log_sync(f"wrote {target.name} for session {args.session_id[:8]}")
19. Print f"Wrote: {target}"

**Error handling per D-30:** The per-session exception handling applies when processing multiple sessions in a loop. For the single-session cmd_write, wrap steps 5-18 in a try/except that catches Exception, prints a useful error with session_id, and sys.exit(1).

**Exit codes per D-31:** 0 = success or correctly skipped, 1 = session failed, 2 = preflight error (handled by \_require_config and \_assert_not_icloud).
