**Session Discovery section** -- discover_sessions(state: dict) -> list:
Per D-07/D-08/D-09:

- Walk PROJECTS_DIR using PROJECTS_DIR.rglob("\*.jsonl")
- Filter to depth 2 only: len(f.relative_to(PROJECTS_DIR).parts) == 2 (this excludes subagent files at depth 4+)
- For each qualifying file, extract: session_id = f.stem, project = f.parent.name, path = str(f), mtime = f.stat().st_mtime, size = f.stat().st_size
- Skip if session_id is in state.get("synced_session_ids", [])
- Skip if fingerprint matches: state.get("fingerprints", {}).get(session_id) == {"mtime": mtime, "size": size} (compare both fields)
- Sort result by mtime ascending (oldest first, per D-08)
- Return list of dicts: [{"session_id": str, "project": str, "path": str, "mtime": float, "size": int}, ...]

**Stub Label Generator section** -- two functions:
Per D-04/D-05/D-06 and RESEARCH.md lines 490-536:

extract_first_user_message(jsonl_path: Path) -> str:

- Open file with encoding="utf-8", errors="replace"
- Iterate lines, skip empty, try json.loads(line)
- Get msg = obj.get("message", obj) (handles both top-level and nested message objects)
- Skip if msg.get("role") != "user"
- Handle content as str or list of content blocks (list: join text parts where b.get("type") == "text")
- Skip system reminders: if "<system-reminder>" in text, continue
- Skip very short messages: if len(text) <= 5, continue
- Return first qualifying text, or empty string on any error
- Include inline comment: "# content can be a string or a list of typed blocks"

make_stub_label(jsonl_path: Path, session_id: str) -> dict:

- Call extract_first_user_message(jsonl_path)

**Slug Generator section** -- make_slug(title: str, fallback_id: str = "") -> str:
Per D-13/D-14 and RESEARCH.md lines 457-475:

- s = unicodedata.normalize("NFKD", title).encode("ascii", "ignore").decode("ascii").lower()
- s = re.sub(r"[^a-z0-9]+", "-", s)
- s = s.strip("-")
- If len(s) > 60: s = s[:60].rstrip("-")
- If not s: s = fallback_id[:8] if fallback_id else "untitled"
- Return s
- Include inline comment: "# NFKD: decomposes accented chars (e -> e + combining accent), then encode drops non-ASCII"

**Session Date Extraction** -- \_get_session_date(jsonl_path: Path) -> str:
Per RESEARCH.md lines 432-451:

- Open JSONL file, iterate first 50 lines
- For each parsed JSON object, check for "timestamp" key
- Parse with datetime.strptime(ts, "%Y-%m-%dT%H:%M:%S.%fZ").replace(tzinfo=timezone.utc)
- Return dt.strftime("%Y-%m-%d")
- Fallback if no timestamp found in first 50 lines: use file mtime via datetime.fromtimestamp(jsonl_path.stat().st_mtime, tz=timezone.utc).strftime("%Y-%m-%d")
- Include inline comment: "# Session date from first JSONL timestamp, NOT file mtime (mtime can drift from backups)"

**YAML Frontmatter Emitter section** -- emit_frontmatter(fields: dict) -> str:
Per RESEARCH.md lines 398-428:

- Hand-rolled YAML emitter (no pyyaml). Block form only.

- For each key, emit based on type:
  - None -> bare "key:" (no value after colon)
  - bool -> lowercase "true" / "false"
  - int -> str(value)
  - list -> block list form: newline then " - item" for each item
  - str -> plain if no YAML-special chars (test with re.search(r'[:#{}[\]|>&!*,]', value)), otherwise double-quoted via json.dumps(value). synced_at always double-quoted.
- Return "---\n" + yaml_lines + "---\n"
