    - Python 3.9+ (`python3 --version`; macOS ships it via Xcode CLT)

    ```bash
    git clone <repo> ~/Projects/claude-chat   # or wherever you keep projects
    mkdir -p ~/.claude-chat
    ln -sf ~/Projects/claude-chat/sync_chats.py ~/.claude-chat/sync_chats.py
    ```
    Explain why symlink (so `git pull` updates the runtime copy). Note: `sync_chats.py` looks for `claude-chat.py` in the same directory as itself — `Path(__file__).resolve().parent` follows the symlink, so `claude-chat.py` is found in the repo clone (RESEARCH §Multi-Machine Onboarding item 3).

