## Trust Boundaries

| Boundary                     | Description                                                                                                                                                                                        |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude Code → hook command   | Claude Code's hook runner invokes the command string verbatim. No user-controlled input flows INTO the command (no interpolation). Hook stdin payload is ignored by --once (RESEARCH §Security).   |
| session JSONL → stub builder | Untrusted content (chat transcripts) is read by `extract_first_user_message`; already scrubbed by Phase 3 before body emits, but `make_stub_label` reads the raw first user message for the title. |
| filesystem → last_run.json   | Only cmd_once writes this file; no untrusted consumer executes its contents.                                                                                                                       |
