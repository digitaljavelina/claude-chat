**Title rules (per D-02, LABEL-03):**

- Verb-leading action phrase (e.g., "Debug RSS feed parsing in homelab service")
- Maximum 10 words
- Use a noun phrase ONLY when the session is purely exploratory with no clear action (e.g., "Python virtual environment options and tradeoffs")
- Do NOT include filler words like "Help with" or "Assist in"

**Gist rules (per LABEL-04):**

- 2-3 sentences in past tense
- Summarize what the user asked and what was accomplished
- Be specific: mention technologies, file names, error types when they are central to the conversation
- Example: "Debugged a failing RSS parser in a Go homelab service. The issue was an unescaped ampersand in feed URLs. Fixed with a pre-parse sanitizer and added a regression test."

**Tag rules (per LABEL-05):**

- 3-5 kebab-case strings (lowercase letters, digits, hyphens only — no spaces, no uppercase, no special characters)
- Store as a JSON array (not comma-separated, not inline #tags)
- Tags should capture: primary language/framework, problem domain, activity type
- Examples: `["python", "virtual-env", "setup"]`, `["go", "rss-parsing", "debugging", "homelab"]`

**Edge-case tag instructions (per D-06, D-07):**

- "If this session is mostly automated tool output with little meaningful human conversation, include `low-signal` in the tags array."
- "If the conversation covers clearly distinct unrelated topics, include `multi-topic` in the tags array."

**Coherence scoring rubric (per D-13, D-14):**

- 5 = Single clear topic, question answered or task completed
- 4 = Single topic, partial resolution or ongoing work
- 3 = Related topics, reasonable conversation flow
- 2 = Multiple loosely related topics, some drift
- 1 = Scattered, abandoned, or incoherent conversation
- "This score is metadata only. Do not skip or treat any session differently based on the score."
