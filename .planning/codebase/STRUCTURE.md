## Naming Conventions

**Files:**

- `claude-chat.py`: Kebab-case, single executable file
- `README.md`, `CLAUDE.local.md`: Markdown documentation

**Directories:**

- `.claude/`, `.planning/`: Hidden metadata directories (dot-prefixed)
- `codebase/`: Lowercase, describes content

**Functions:**

- `cmd_*`: Command handlers (cmd_list, cmd_export, etc.)
- `export_*`: Export formatters (export_markdown, export_html, etc.)
- `_*`: Private/internal functions (leading underscore)
- Uppercase: Constants (CLAUDE_DIR, BACKUP_DIR, HTML_TEMPLATE)

**Classes:**

- `PascalCase`: Message, ToolCall, Session, ChatHandler (inner class)
- `__slots__`: Used in data model classes for memory efficiency

**Variables:**

- `snake_case`: All local and module-level variables (sessions, session_id, short_id, etc.)
- `UPPER_CASE`: Constants only

**Parameters:**

- Short predictable names: `s` (Session), `m` (Message), `tc` (ToolCall), `args` (argparse Namespace)

## Session File Storage

**Location:** `~/.claude/projects/{project_name}/{uuid}.jsonl`

**Format:** Line-delimited JSON (JSONL)

- Each line: Single JSON object representing message or metadata
- Parsed by: `Session.parse()` at lines 158-213
- Structure: Expects "message" key with "role", "content", "model"
- Content variations: Strings or lists (text blocks, tool_use blocks, thinking blocks)

**Discovery:** `find_all_sessions()` scans all project directories for \*.jsonl files
